# furiousgarden-next
Second iteration for Furious Garden

This project is for a carnivorous plant web store that I wish to include social media elements on in the future. 
I had begun to make this site a year ago but have since learned a lot more in the coding realm and wished to
rebuild from the ground up in order to create the product I wanted in the beginning. This project is coded using
React and JavaScript(to be changed to TypeScript once the project is stable) and uses minimal dependencies to 
provide the features. The project will start with a catalog and blog and will grow to incorporate user features.

Some ideas for the future:
- Comments on products with review capabilities
- Enhanced blog features to also incorporate comments and discussion
- A forum for conversing and trading among users to build a web community
- Interactive calendar utilizing google maps to show future events
- Interactive game(s) to provide discount codes for products(throwback to the early internet days lol).
- Smooth/fluid transitions based on device

Will add and remove ideas as they come. For now I wanted to log immediate/intermediate goals and growth of the project 
as it happens.
